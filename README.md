# Andy’s Goals

Mobile-first AI learning hub.

## GitHub structure

Keep all six visible files in the repository root:
- server.js
- package.json
- README.md
- index.html
- app.js
- styles.css

The `.env` file must never be uploaded to GitHub.

## Deployment

Use a Node web service. Build/install command:
npm install

Start command:
npm start

Environment variables:
OPENAI_API_KEY=your_api_key
OPENAI_MODEL=your_available_model
